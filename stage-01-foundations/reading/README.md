# Reading material for Stage 1

Three files, one per topic folder in `src/`. Each one explains the same thing the code demonstrates, just in more depth, and points at the best current material on it, not a random link dump.

Read the file for a topic either before or after you run that topic's code. Both orders work. What matters is that you read it once, not that you memorize it.

- [02_same_prompt_different_answers.md](./02_same_prompt_different_answers.md)
- [03_attention_rough_shape.md](./03_attention_rough_shape.md)
- [04_mixture_of_experts.md](./04_mixture_of_experts.md)

Resources are not repeated across stages. If something genuinely belongs in two places, it'll be linked once here and referenced by name later, not copy-pasted again.
